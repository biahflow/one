# As sobrevivências decididas do vocabulário canônico (Issue #91, Language Map v1.1).
#
# Formato: caminho::regra::identificador::contagem
#
# Quem a lê é `apps/api/tests/test_vocabulary.py`, e ela **só encolhe**. Não há
# `review_by` e não há prazo — ao contrário do `docs/security/advisories.json` e no
# precedente do `PINNED_BY_EXCEPTION` (ADR 0063) e do `FOUNDATION_WITHOUT_A_LINE`
# (ADR 0054): dívida de vocabulário não caduca por calendário, ela some no dia em que
# o termo sai do código. O vencimento de cada linha abaixo é
# `test_the_allowlist_does_not_keep_a_line_that_stopped_being_needed`, que reprova
# quando a ocorrência desaparece **ou** quando a contagem cai.
#
# A contagem é campo separado de propósito: uma ocorrência nova sob uma chave já
# isenta reprova, em vez de pegar carona na isenção da vizinha.
#
# Toda linha tem a razão escrita imediatamente acima dela, e a asserção que a cobra
# tem piso — uma sobrevivência cuja razão ninguém consegue escrever é uma
# sobrevivência que não devia existir (o argumento da lista positiva da ADR 0082).
#
# Esta lista **não nasceu vazia**, e isso é a decisão. Uma allowlist vazia é o defeito
# que a ADR 0033 nomeou ("seguia vazia porque nada a consultava") e a asserção sobre
# lista vazia que a ADR 0082 registrou ("não percorre ramo nenhum").
