## Goal

O shell passa a usar as primitivas `components/one/StatePill.tsx` e `components/one/Button.tsx` em
vez de desenhar estado e botão à mão. Verificável: os estados no shell renderizam via `<StatePill>`
(ícone junto do texto) e os botões via `<Button>`; os seletores legados de estado/botão que ficaram
órfãos saem de `app/globals.css`.

## Scope

- `app/DashboardClient.tsx` — substituir o desenho à mão de estado (`.state--*`, `.health-pill`,
  `.priority-pill`) por `<StatePill variant=…>`; substituir os botões crus (`.ai-button`,
  `.text-button`) por `<Button variant=…>`.
- `app/globals.css` — remover **apenas** os seletores de estado/botão que ficarem sem uso após a
  substituição.

## Out of Scope

- Alterar as primitivas `components/one/StatePill.tsx`/`Button.tsx` (esta fatia as **adota**).
- O mapa de cor de §1/§2 (T02/T03).
- Migrar qualquer mapeamento de JSON de API para `components/` — a guarda de consumo de
  `tests/api-contract.test.mjs` varre só `app/`; primitiva é apresentação.

## Acceptance Criteria

- `inertButtons()` verde — todo `<button>` sob `app/` e `components/` tem `onClick` ou
  `type="submit"`; a primitiva `Button` satisfaz por construção. Como se checa: `npm test`
  (roda `tests/rendered-html.test.mjs`).
- Os estados renderizam ícone junto do texto (via `StatePill`).
- Nenhum seletor de estado/botão legado sem uso em `app/globals.css`.
- Dado inalterado: `npm run test:contract` verde.
