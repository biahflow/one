## Known Risks

- Reserializar um timestamp: se `build_dashboard` já entrega `observed_at.isoformat()` (string), o
  schema deve declarar `str`, senão o Pydantic reserializa e muda o byte prometido.
- Esquecer de regenerar `openapi.json` deixa o gate de deriva vermelho.
- Adicionar um campo cujo nome case a lista de segredos de `telemetry.py` reprova o contrato — nomes
  como `observed_at`/`projection_version`/`synced_at` são seguros; evite qualquer coisa com `token`,
  `key`, `secret`.
